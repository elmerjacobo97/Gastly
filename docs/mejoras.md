Sí. Ya tienes una base bastante útil. Las mejoras que más sentido tienen ahora serían estas, en orden:

1. Mejorar el Resumen
   Mostrar una explicación más clara del cálculo:
   Ingreso estimado

- Ahorro obligatorio
- Pagos recurrentes del mes
  = Disponible libre
- Gastos variables reales
  = Restante
  Esto haría que el semáforo sea más confiable y entendible.

2. Estados En Pagos Recurrentes
   Cambiar textos como vimos:
   A pagar este mes
   Total recurrentes activos
   Pagado este mes
   Falta pagar este mes
   También marcar pagos como:
   Vence pronto
   Vencido
   Pagado
   Pendiente
3. Registrar Ingreso Desde Plan Mensual
   En Plan mensual, botón:
   Registrar sueldo como ingreso
   Con tu caso:
   Sueldo: S/ 2217.50
   Categoría: Sueldo
   Así no tienes que ir manualmente a Movimientos.
4. Plantillas De Categorías Iniciales
   Cuando un usuario nuevo entra, crear categorías sugeridas:
   Sueldo
   Comida
   Servicios
   Software
   Cuidado personal
   Transporte
   Salidas
   Compras
   Ahorro
   Con iconos y colores ya definidos.
5. Mejorar Presupuesto
   Ahora mismo presupuesto sirve, pero podría ser más conectado al plan:
   Disponible libre: S/ 1200
   Presupuestado: S/ 900
   Sin asignar: S/ 300
   Eso te ayuda a repartir todo tu dinero libre.
6. Alertas Inteligentes
   Mostrar mensajes tipo:
   Ya usaste 80% de Salidas
   Claude Code vence en 3 días
   Tienes S/ 250 libres para el resto del mes
   Te quedan S/ 18 diarios disponibles
7. Gasto Diario Disponible
   Muy útil para control personal:
   Restante libre: S/ 600
   Días restantes del mes: 15
   Puedes gastar: S/ 40 por día
8. Mejorar Reportes
   Agregar filtros por categoría, tipo y rango personalizado.
   También gráficos como:
   Gastos recurrentes vs variables
   Ahorro proyectado anual
   Top categorías
9. Historial De Pagos Recurrentes
   Dentro de un pago recurrente, ver:
   Claude Code
   Mayo: S/ 68.23
   Junio: S/ 75.10
   Julio: S/ 73.80
   Muy útil para variables como servicios o USD convertido a soles.
10. Dashboard De Próximos Pagos
    Una lista en resumen:
    Próximos 7 días:

- Claude Code: S/ 68.23
- Celular: S/ 39.90
  Mi recomendación inmediata sería hacer primero:

1. Mejorar Resumen
2. Mejorar etiquetas/estados en Pagos recurrentes
3. Agregar gasto diario disponible
   Eso haría que la app se sienta mucho más inteligente sin complicarla demasiado.
